## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services. It provides more than 200 services covering computing, storage, networking, databases, analytics, artificial intelligence, and security.

---

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the best choice for organizations that use Windows Server, Microsoft 365, and Active Directory because it provides seamless integration with Microsoft's ecosystem.

---

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform (GCP) is recognized for its strong AI, machine learning, and Kubernetes capabilities. Google also developed Kubernetes and offers Google Kubernetes Engine (GKE).

---

### 4. Which cloud platform would you personally choose and why?

I would choose AWS because it offers the largest selection of cloud services, a global infrastructure, excellent scalability, and strong community support, making it suitable for many different business needs.
